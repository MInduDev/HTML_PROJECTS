# HTML Projects 🌐

A collection of my **HTML-based projects** created during my web development learning journey.

This repository contains my practice work, frontend projects, and complete website projects, organized into different categories based on their **size, complexity, and purpose**.

---

## 📚 About This Repository

I created this repository to keep my HTML and web development projects organized in one place.

The projects range from small HTML practice exercises to complete frontend websites. This repository also documents my progress as I learned and applied HTML, CSS, Bootstrap, JavaScript, and other frontend technologies.

### What you'll find here:

- 🧩 Small HTML practice projects
- 🎨 Frontend website projects
- 🌐 Complete website projects
- 📱 Responsive webpage designs
- 🏗️ Website layouts and components
- 📄 Forms, tables, and HTML elements
- ⚡ Interactive frontend projects
- 📈 Projects showing my learning progress

---

## 🗂️ Project Categories

The projects are divided into three main categories:

### 1. 🧩 HTML Small Projects

Small projects created to practice individual HTML concepts and basic webpage structures.

These projects may include:

- Basic HTML pages
- Forms
- Tables
- Lists
- Navigation
- Images and multimedia
- Basic webpage layouts

---

### 2. 🎨 HTML Frontend Projects

Frontend-focused projects created using HTML along with CSS, Bootstrap, JavaScript, and other frontend technologies.

These projects focus more on:

- UI design
- Responsive layouts
- Landing pages
- Website components
- Interactive elements
- Modern webpage layouts

---

### 3. 🌐 HTML Full Projects

Larger and more complete website projects that combine multiple pages, sections, features, and frontend functionality.

These projects may include:

- Complete website layouts
- Multiple sections/pages
- Responsive design
- Forms and user interactions
- JavaScript functionality
- E-commerce interfaces
- Business and service websites
