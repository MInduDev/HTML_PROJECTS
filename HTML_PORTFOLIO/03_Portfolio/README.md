M. Indu — Portfolio
A personal portfolio website showcasing my profile, technical skills, experience, projects, education, certifications, and contact information.

About
I am an MCA graduate and Full Stack Web Developer interested in building responsive and user-friendly web applications. This portfolio brings together my development work, technical background, and professional information.

Features
- Responsive layout for desktop, tablet, and mobile screens
- About section with profile information and highlights
- Technical skills grouped by category
- Experience timeline
- Featured project gallery
- Education details
- Certifications and awards section
- Resume download
- Contact section with email and social links
- Smooth scrolling navigation and active navigation states
- Scroll-reveal effects, loading screen, and back-to-top button
- Animated role text in the hero section

Tech Stack
- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.2
- Font Awesome 6.5.0
- Google Fonts — Playfair Display and DM Sans

Run Locally
1. Clone this repository:
   "git clone https://github.com/MInduDev/HTML_PROJECTS.git"
2. Open the HTML_PORTFOLIO/03_Portfolio folder.
3. Open index.html in your browser.
You can also open the project folder in Visual Studio Code and use the Live Server extension.
